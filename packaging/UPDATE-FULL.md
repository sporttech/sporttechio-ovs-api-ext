# Установка / полное обновление vmix-адаптера

Инструкция для операторов: этот архив содержит адаптер **вместе с** `node_modules`. `npm install` на машине оператора **не нужен**.

## Шаги

1. Остановите адаптер (закройте окно `node` или нажмите Ctrl+C).
2. Сделайте копию рабочей папки адаптера (на случай отката).
3. Распакуйте этот zip-архив.
4. Скопируйте содержимое папки `sporttech-api-ext-full` **поверх** существующей папки адаптера (замените файлы при запросе), **включая** папку `node_modules`.
5. **Не** заменяйте файл `.env`. Оставьте свой текущий `.env` (обычно с `localhost`). В архиве `.env` нет намеренно.
6. Запустите адаптер из его папки:

```bat
node index.js
```

`npm install` делать **не нужно**.
