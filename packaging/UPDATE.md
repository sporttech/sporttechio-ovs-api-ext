# Обновление vmix-адаптера

Инструкция для операторов: наложить обновление поверх уже установленной копии адаптера **без** повторного `npm install` (если зависимости не менялись).

## Шаги

1. Остановите адаптер (закройте окно `node` или нажмите Ctrl+C).
2. Сделайте копию рабочей папки адаптера (на случай отката).
3. Распакуйте этот zip-архив.
4. Скопируйте содержимое папки `sporttech-api-ext-update` **поверх** существующей папки адаптера (замените файлы при запросе).
5. **Не** копируйте и **не** удаляйте папку `node_modules` на компьютере оператора.
6. **Не** заменяйте файл `.env`. Оставьте свой текущий `.env` (обычно с `localhost`). В архиве `.env` нет намеренно.
7. Запустите адаптер из его папки:

```bat
node index.js
```

`npm install` делать **не нужно**, если адаптер стартует без ошибок.

## Если не хватает модулей

Если в консоли появляется ошибка вида `Cannot find module '...'` (например `pako` — зависимость для gzip SSE), один раз выполните:

```bat
npm install
```

Затем снова:

```bat
node index.js
```
